# 📊 DataMind AI

### Your Data. Your Questions. Intelligent Insights.

**DataMind AI** is an AI-powered data analytics workspace built with Python and Streamlit. It brings together automated data profiling, exploratory data analysis, interactive visualisations, natural-language analytics, and executive report generation in a single application.

It helps users transform raw CSV datasets into meaningful, data-backed insights through an intuitive analytical workspace.

---

## ✨ Key Features

### 🔍 1. Data Health Audit
Understand the structure and quality of your datasets.

- Dataset overview: rows, columns, duplicate records, and memory usage.
- Column-level information and data types.
- Missing-value counts and percentages.
- Interactive dataset preview.
- Automated data-quality inspection.

### 📈 2. Exploratory Data Analysis (EDA)
Discover statistical patterns and relationships within your data.

- Numerical and categorical statistical summaries.
- Correlation analysis with interactive heatmaps.
- IQR-based outlier detection.
- Histograms and box plots.
- Categorical feature distribution visualisations.
- Interactive charts using Plotly.
- Automatic identification of likely identifier and high-cardinality columns to improve default analysis.

### 🤖 3. AI Data Analyst
Explore datasets using natural-language questions through an LLM-powered analytical assistant.

- Ask questions about uploaded datasets.
- Translate natural-language queries into structured analytical tool calls.
- Perform data-backed calculations using predefined Python and Pandas functions.
- Generate relevant charts and visualisations.
- Receive natural-language explanations of analytical results.
- Support conversational context and follow-up questions.

**How it works:** The language model interprets the user's question and selects from predefined analytical tools. Python performs the actual calculations on the dataset, and the model communicates the results in an understandable format.

The application uses controlled analytical functions rather than executing arbitrary Python code generated by the language model.

### 📑 4. Executive Report Generator
Generate downloadable reports summarising important dataset findings.

- Dataset overview and statistics.
- Data-quality findings.
- Numerical and categorical summaries.
- Correlation analysis.
- Outlier observations.
- Automatically generated executive findings.
- Export reports in **PDF and Markdown** formats.

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.10 or later
- Git
- OpenRouter API key for AI-powered functionality

### 1. Clone the repository

```bash
git clone https://github.com/SoumiliG308/DataMind-AI.git
```

### 2. Navigate to the project directory

```bash
cd DataMind-AI
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

Activate the environment:

**Windows**
```bash
venv\Scripts\activate
```

**macOS / Linux**
```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure API credentials

Create a `.streamlit` directory in the project root and add a file named `secrets.toml`.

Add your OpenRouter API key:

```toml
OPENROUTER_API_KEY = "your_api_key_here"
```

For Streamlit Community Cloud deployment, configure the API key under the application's **Settings → Secrets** section.

### 6. Run the application

```bash
streamlit run app.py
```

The application will open in your default browser.

## 🔐 Security and Data Handling

- API credentials are managed separately using Streamlit secrets.
- Sensitive configuration files are excluded from version control.
- AI-generated analytical operations are restricted to predefined tools.
- Dataset calculations are performed using controlled Python-based functions rather than arbitrary LLM-generated code.
